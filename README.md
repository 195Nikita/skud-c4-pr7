Автор: Борцов Никита Александрович. Вариант 2. Группа И 14 23 9.

Проектирование архитектуры, а не реализованная система. Стек C# / WPF / ASP.NET Core / PostgreSQL является проектным решением.

## Уровни C4

1. [Контекст](01-context.mmd) — система, оператор и внешние контроллеры.
2. [Контейнеры](02-container.mmd) — WPF-клиент, API-шлюз и единая БД.
3. [Компоненты шлюза](03-gateway.mmd).
4. [Компоненты клиента](04-client.mmd).

Исходники используют нотацию Mermaid C4. Для просмотра вставьте содержимое .mmd в блок Mermaid в Markdown или откройте в Mermaid Live Editor. PNG представляют цветные схемы тех же основных элементов; .mmd дополнительно показывают внешних вызывающих участников. Уровень Code не добавлен: для задания о модулях достаточно уровней 1–3.

Цвет дополняет явную подпись типа элемента. Сам C4 не закрепляет обязательную палитру: выбранная схема оформления применяется последовательно на всех уровнях.

## Исправления

Контроллеры турникетов вынесены за границу программной АИС. Пропуска и журнал — таблицы одного хранилища PostgreSQL. Компоненты показаны внутри конкретного приложения. Идентификация находится внутри шлюза; отдельный внешний IdP не предполагается. Решение check возвращается в HTTP-ответе, контроллер открывает турникет самостоятельно. Факт физического прохода не следует путать с решением о доступе.
